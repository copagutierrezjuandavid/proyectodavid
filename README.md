# Lavado de Autos Apaza
Este sitio web tiene como objetivo dar a conocer los servicios de Lavado de Autos Apaza, ubicado en la ciudad de Oruro, Bolivia. Está dirigido a personas que desean consultar los servicios, precios y ubicación del negocio, así como comunicarse fácilmente para realizar consultas o reservas. De esta manera, facilita el acceso a la información y mejora la comunicación con los clientes.
# Contenido del sitio
Servicios y precios: información sobre los lavados disponibles y sus costos.
Ubicación y contacto: dirección del negocio, Google Maps y acceso a WhatsApp.
Diseño adaptable: compatible con computadoras y dispositivos móviles.
Funciones adicionales: modo claro y oscuro y formulario de contacto con validación mediante JavaScript.
